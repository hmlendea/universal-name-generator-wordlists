## 🔎 What This Document Covers

This document describes how Universal Name Generator — Wordlists at https://github.com/hmlendea/universal-name-generator-wordlists manages personal data. It covers the repository contents and verified integrations described below. This is an assets-only repository containing curated wordlist data files; no application code, user accounts, or data processing services are included here.

## 📥 Data We Handle

### Data Provided to the Application

No personal data is requested, collected, or stored by this repository. The repository contains only curated wordlist assets (plain text `.lst` files) organised by universe and category for name generation.

### Data Generated or Collected by the Application

No personal data is generated or collected automatically by this repository. GitHub may collect standard repository analytics (stars, forks, clones, traffic) as part of its platform operation; these are governed by GitHub's privacy policy.

### Data Received from Integrations

No personal data is received from integrations or third parties. The repository has no built-in external data transfer mechanisms.

## 🧭 Processing and Use

The repository provides static wordlist data files for consumption by name generation applications. No personal data processing occurs within this repository.

## 🗄️ Storage, Retention, and Deletion

The repository stores only wordlist data files (`.lst` files) and schema definitions (`GenerationSchemas.xml`) in the Git repository history. No personal data is stored. Repository data persists according to GitHub's repository retention policies. Contributors may request removal of their contributions through standard GitHub processes.

## 🔗 External Processing and Integrations

The application has no built-in external data transfer. GitHub Actions workflows may execute in GitHub-hosted runners for continuous integration; any data processed by GitHub Actions is governed by GitHub's privacy policy and the workflow configurations in this repository.

| Service or integration | Purpose | Data involved | Configuration or documentation |
|-----------------------|---------|---------------|--------------------------------|
| GitHub Actions | Continuous integration | Repository contents, workflow logs | `.github/workflows/` |
