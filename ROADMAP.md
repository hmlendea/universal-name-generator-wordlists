## 🎯 Current Focus

- **Status: In Progress**: Schema and validation expansion - Extend schema coverage and strengthen structural validation for active dataset categories.
- **Status: In Progress**: Data quality and curation baseline - Reduce duplicates and regularise formatting inconsistencies while preserving dataset authenticity.
- **Status: Planned**: Contributor workflow reinforcement - Improve contribution guidance and validation expectations for consistent pull requests.

## 🗺️ Planned Labour

### No Fixed Horizon

- Define canonical formatting conventions for all `.lst` datasets with practical examples.
- Add repository-wide duplicate detection reporting and curate a baseline remediation pass.
- Fill category gaps in existing universes before introducing wholly new universes.
- Extend underrepresented real-world language families and fictional factions.
- Refine directory taxonomy where equivalent categories currently diverge, while preserving compatibility.
- Improve repository navigation in documentation for large directory trees.

## ⚠️ Dependencies and Risks

- Source diversity variance - Inconsistent origin quality may reduce dataset consistency - Mitigation: apply repeatable validation and curated review passes.
- Taxonomy drift - Incremental additions may fragment naming conventions - Mitigation: document canonical structure and review structural changes before merge.
- Contribution variability - Heterogeneous submission styles may introduce regressions - Mitigation: reinforce contribution guidance and validation expectations.

## 🚫 Out of Scope

- Generator application logic, runtime execution, or API behaviour changes.
- Repository migration into a compiled-code project structure.
- Forced stylistic homogenisation that erodes setting-specific naming identity.
